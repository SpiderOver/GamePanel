FEATURES

Everything needed for day-to-day administration.

GamePanel is designed around a private server operator workflow rather than a public hosting marketplace.

⏻

Server lifecycle

Start, stop, restart and monitor the server host from one interface.

▱

Profiles & files

Manage server profiles, configuration files, directories and game-specific settings.

⌘

Console access

Use administrative consoles for the Raspberry Pi and Xeon server without leaving the panel.

◫

Backups

Automatic and manual backups, retention controls and safe restore workflows.

♟

Player management

Inspect connected players and perform common server administration tasks.

＋

Mod management

Search, inspect, install, enable and disable compatible Minecraft mods.

CURSEFORGE CORE / 3RD PARTY API

CurseForge-powered discovery without becoming a mod mirror.

The integration is built for explicit administrator actions on a self-hosted server. CurseForge remains the authoritative source for project metadata and permitted files.

✓

Search Minecraft projects
Find mods directly from the administration panel.

✓

Compatibility filtering
Filter releases using the active Minecraft version and mod loader.

✓

Project attribution
Show project identity, authors, metadata and links back to CurseForge.

✓

Explicit downloads only
Files are requested only after an administrator chooses a release and only when the API permits access.

✓

Low-volume usage
Metadata is cached where appropriate to avoid unnecessary API requests.

✓

No public redistribution
GamePanel is not intended to host or mirror CurseForge content for third parties.
