GamePanel
GamePanel is a self-hosted game server administration panel focused on Minecraft server management.
It provides server lifecycle controls, profiles, file management, configuration editing, player management, backups, monitoring, console access and mod management.
CurseForge integration
GamePanel integrates with the CurseForge Core API to:
- Search Minecraft mods
- Display project metadata, authors and icons
- Filter releases by Minecraft version and mod loader
- Install compatible releases
- Switch between compatible mod versions
- Enable and disable locally installed mods
GamePanel does not operate a public mod mirror. Files are downloaded only on explicit administrator request and only when their distribution is permitted through the CurseForge API.
Project status
GamePanel is currently a personal, non-commercial, self-hosted project under active development.
